# Issue Tracker

Welcome to the official BattleCapes issue tracker.

This repository is dedicated to reporting bugs, suggesting new features, and sharing feedback about BattleCapes.

## Submitting an Issue

Choose the appropriate template when creating a new issue:

- **Bug Report**: Report bugs and unexpected behavior.
- **Feature Request**: Suggest new features and improvements.
- **General Feedback**: Share your thoughts, opinions, and suggestions.

## Before Submitting

- Check existing issues to avoid duplicates.
- Provide as much relevant information as possible.
- Keep discussions respectful and constructive.
